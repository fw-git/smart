### **[프로젝트] 퓨처워크(Future Work) 공식 웹사이트 구축 및 배포**

* **작업 기간**: 2024.08 ~ 2024.10 (약 2개월)
* **담당 역할**: UI/UX 디자인, Web 퍼블리싱 & Frontend 개발, GitHub Pages CI/CD 배포 및 커스텀 도메인/DNS 설정 (100% 1인 단독 수행)
* **고객사 / 대상**: (주)퓨처워크 (Smart Factory, Smart Drone, Smart Farm 솔루션)
* **환경 / 기종**: Web (Desktop / Mobile Responsive), GitHub Pages Engine, Custom Domain
* **Tech Stack**:
  * **Design & UI**: Figma, Responsive Web Publishing
  * **Frontend**: HTML5, CSS3, JavaScript (Vanilla JS / ES6+)
  * **CI/CD & Deployment**: GitHub, GitHub Pages, Custom Domain (DNS A/CNAME 레코드 연동), Enforced HTTPS (SSL/TLS Certificate)

---

#### **1. Key Achievements (주요 성과)**
* **End-to-End 단독 완수**: 기획/디자인(Figma)부터 HTML/CSS/JS 기반 퍼블리싱, GitHub Pages 자동 배포 파이프라인 구축 및 커스텀 도메인 연결까지 전 과정을 1인 풀스택으로 완수
* **브랜드 정체성 시각화**: 스마트 공장, 스마트 드론, 스마트 팜 등 기업의 핵심 사업 영역을 직관적으로 전달하는 디자인 및 UI/UX 구현
* **무비용·고효율 서버리스 배포**: 별도 서버 관리나 비용 없이 GitHub Pages를 활용해 고가용성 static 웹 호스팅 환경을 구성하고, HTTPS 보안 통신 적용
* **반응형 웹 최적화**: Cross-Browsing 대응 및 Mobile/Desktop 환경에 부드럽게 반응하는 Responsive 레이아웃 구현

---

#### **2. Detailed Responsibilities (상세 업무 내용)**

**🎨 UI/UX 디자인 & 퍼블리싱 (Design & Publishing)**
* Figma를 활용해 브랜드 아이덴티티에 맞는 컬러 팔레트, 타이포그래피, 레이아웃 및 와이어프레임 설계
* 스마트 공장(인쇄 관리/산단 혁신), 스마트 드론(자율비행/응용사례), 스마트 팜 등 주요 사업군 섹션 카드 및 드롭다운 UI 구현
* Media Query 기반의 반응형 웹 퍼블리싱으로 모바일 및 데스크톱 모니터 최적화

**💻 Frontend 개발 (Web Frontend / Vanilla JS)**
* 프레임워크 없이 순수 **HTML5 / CSS3 / JavaScript (Vanilla JS)** 기반 구조 작성으로 가볍고 빠른 웹 페이지 성능 확보
* 메인 비주얼 섹션, 사업 영역별(스마트 공장/드론/팜) Interactive UI 및 아코디언/드롭다운 동작 script 구현
* 이메일 문의 접수(`help@ftwk.co.kr`) 및 상단 네비게이션 섹션 이동 UX 적용

**⚙️ Deployment & Infra (GitHub Pages & Domain)**
* **자동 배포 파이프라인 구축**: GitHub Repository의 `main` 브랜치 연동 기반 GitHub Pages 빌드/배포 환경 세팅
* **커스텀 도메인 & DNS 연결**: 구매한 커스텀 도메인([ftwk.co.kr](https://ftwk.co.kr/))의 CNAME/A Record DNS 레코드 설정 및 repository 내 `CNAME` 파일 구성
* **보안 강화**: GitHub Pages 제공 SSL/TLS 인증서를 적용하여 **Enforce HTTPS** 설정 완결

---

#### **3. Self-Evaluation / Project Retrospective (프로젝트 소회)**
기업의 브랜딩 웹사이트를 Figma 디자인부터 순수 HTML/CSS/JS 기반 Front-End 구현, 그리고 **GitHub Pages를 활용한 Serverless 배포 및 커스텀 도메인 연동**까지 단독으로 완수한 프로젝트입니다. 외부 라이브러리/프레임워크 의존도를 줄여 웹 기본기를 입증하고, 서버 운영 비용을 최소화하면서 안정적인 웹 호스팅 환경을 완성했습니다.
